# How Does a Kingdom Collapse?

**Series:** Worldcraft Shorts · Episode 19  
**Lesson:** Collapse is a feedback loop, not a villain or a single disaster. Economic strain, corruption, revolt, military overreach, succession crises and lost legitimacy each make the next worse, until an ordinary event breaks a system that's already cracked.
