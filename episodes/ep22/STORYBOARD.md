# The Most Dangerous Magic Is Cheap Magic

**Series:** Worldcraft Shorts · Episode 22  
**Lesson:** Powerful magic changes society, and cheap magic changes it most, because everyone uses it. Free healing would erase surgery, prolong wars (no wound sends a soldier home) and make healers the ruling class. Follow every cheap power outward; and if anyone in the story still dies of a wound, the world has to explain why.
